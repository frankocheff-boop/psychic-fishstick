# Booking Menu System

A simple, elegant booking menu application for reservations and appointments.

## Features

- 📅 Date and time selection
- 👥 Guest count management
- 📧 Email confirmation
- 📱 Responsive design for mobile and desktop
- ✅ Form validation
- 🎨 Modern, gradient UI

## Usage

Simply open `index.html` in your web browser to start using the booking menu.

### Booking Process

1. Fill in your personal information (name, email, phone)
2. Select your preferred date and time
3. Choose the number of guests
4. Select the service type (Restaurant, Event Space, Private Room, or Catering)
5. Add any special requests (optional)
6. Click "Submit Booking" to confirm

### Features Included

- **Form Validation**: Ensures all required fields are completed correctly
- **Date Validation**: Prevents booking dates in the past
- **Responsive Design**: Works seamlessly on mobile, tablet, and desktop devices
- **Confirmation Page**: Displays booking details after submission
- **Security**: HTML escaping to prevent XSS attacks

## Files

- `index.html` - Main HTML structure
- `styles.css` - Styling and responsive design
- `script.js` - Form validation and interaction logic
